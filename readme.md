## Project Overview
This project presents a research-focused implementation of a Deep Reinforcement Learning (RL) visual attention model. It evaluates whether framing medical image classification (Chest X-Rays) as a sequential Markov Decision Process (MDP) allows an RL agent to match the diagnostic accuracy of traditional CNNs while reducing the computational footprint by selectively "glimpsing" at image patches. 

The architecture utilizes a Double Deep Q-Network (DDQN) built in TensorFlow, interacting with a custom Gymnasium environment.

------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------

## Project Structure
The codebase is modularized into six Python scripts and several designated directories:

### 1. `utils.py`
Handles data ingestion, label preprocessing, and calculating F1/AUC evaluation metrics.
* **`load_chexpert_labels()`**: Loads and cleans the metadata.
* **`calculate_metrics()`**: Computes validation scores.

### 2. `env.py`
Contains the custom `XRayAttentionEnv` Gymnasium environment. Manages the internal $(x, y)$ coordinate state, cropping limits, the 10-step temporal threshold, and the asymmetric reward shaping math.

### 3. `model.py`
* **`build_dqn_agent()`**: Constructs the shallow, 4-layer CNN backbone combined with Dense layers for Q-Value output to prevent gradient instability.

### 4. `train.py`
* **`DQNTrainer()`**: Manages the Experience Replay Buffer, the conservative epsilon-greedy decay strategy, and the Huber loss temporal difference calculations for Double Q-learning.

### 5. `main.py`
The primary orchestrator script. Instantiates the environment and agent, runs the 15,000-episode training loop, triggers validation checks every 500 episodes, and exports the resulting CSV data files.

### 6. `plots.py`
Generates visualization artifacts for the final report using the exported CSV data.
* **`plot_training_rewards.jpg`**: Cumulative reward trends.
* **`plot_training_steps.jpg`**: Agent delay tactics and step counts.
* **`plot_training_loss.png`**: Huber loss stability over time.
* **`plot_validation_metrics.png`**: F1 and AUC progression.
* **`plot_confusion_matrix.png`**: Evaluation of false-positive "paranoia."
* **`plot_agent_trajectory.png`**: Visual mapping of the agent's $(x, y)$ coordinate search path.

### 7. `data/`

### 8. `saved_models/`
**[IMPORTANT]** You must create this empty directory before running `main.py`. The DDQN agent will automatically checkpoint and save its `.h5` neural network weights into this folder every 500 episodes.

### 9. `output/`
Folder designated for the CSV outputs generated by `main.py` (e.g., `training_metrics.csv`, `validation_metrics.csv`, `trajectory_data.csv`) and the resulting PNG/JPG visualizations generated by `plots.py`.
